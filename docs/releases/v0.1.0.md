# DevDigi Music v0.1.0 — First Sound

## Summary

First Sound is the first usable DevDigi Music Android release. It provides a
native Kotlin/Jetpack Compose client for a user-provided
Navidrome/OpenSubsonic server, with secure account authentication, library
browsing and native Media3 playback.

## What's New

- Configure and connect to a compatible user-provided Navidrome/OpenSubsonic
  server.
- Authenticate securely with encrypted credential storage, validated session
  restoration and explicit sign-out.
- Browse recent albums, open album details and view ordered tracks.
- Play FLAC and other supported media through native AndroidX Media3 playback.
- Use an account-scoped persistent playback queue with Previous/Next controls.
- Keep playback active in the background and control it through Android system,
  notification and lock-screen media surfaces.
- Navigate the First Sound Compose shell through Home and Library, with a
  persistent mini-player and Now Playing surface.

## Improvements

- Synthetic Navidrome integration coverage for deterministic CI validation.
- Privacy-safe real-device and real-instance validation.
- Account/server isolation across authentication, library state, playback and
  persistent queue ownership.
- Secure Android release signing with verified APK/AAB provenance.

## Known Limitations

- Search and Discover are currently explicit placeholders.
- Offline downloads are not included in First Sound.
- Queue editing is not yet available.
- Remote playback targets, Cast and Music Connect are not included.
- The app currently manages one selected server profile and active account
  session rather than providing a general multi-account session manager.
- Firebase App Distribution and automated Google Play publishing are planned
  follow-up release-engineering work.
